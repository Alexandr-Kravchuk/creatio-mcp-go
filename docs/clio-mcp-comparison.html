What it is

Same tools, different implementation

clio MCP

  • the mcp-server mode of clio, the .NET CLI for Creatio
  • 235 tools in clio 8.1.0.142
  • needs .NET; installed as a .NET tool
  • registers environments (reg-web-app), deploys and restores stands, installs the knowledge library and updates it hourly

creatio-mcp-go

  • a separate MCP server written in Go, MIT, public repository
  • 200 of clio’s 235 tools: same names, arguments, contracts and answer shapes
  • one file, no .NET; install.sh, install.ps1 or Homebrew
  • reads environments from clio’s appsettings.json; one process serves them all
  • v0.2.1, pre-release of 2026-10-23

creatio-mcp-go v0.2.1 · clio 8.1.0.142

2 / 12

creatio-mcp-go answers clio’s tools with the same names, arguments, contracts and answer shapes as clio 8.1.0.142. It does not register environments itself: it reads clio’s appsettings.json, so registration stays with clio reg-web-app. Without clio, one environment can be set with CREATIO_URL, CREATIO_LOGIN and CREATIO_PASSWORD. Sources: README.md, docs/install.md.

creatio-mcp-go: pros

What switching to creatio-mcp-go gives

Faster where clio spends time on itself

Start 0.04–0.06 s vs 3.2–3.9 s; list-pages 0.14 s vs 4.74 s; reads overall 2.7 times faster.

Short write steps take under a second

Restart without waiting: 0.6 s vs 2.5–3.1 s. Where clio’s extra time goes was not established.

One file, no .NET

23 MB on disk and 24–28 MB of memory; clio takes 504 MB plus .NET and 136–170 MB.

Agents and skills work unchanged

1025 contracts match clio 8.1.0.142, 0 unexplained differences; the same 74 prompts and guidance.

Updates without stopping the server

A running server keeps working. On Windows a clio update fails while clio mcp-server runs.

One-command install

install.sh and install.ps1 check SHA256 and register the server in Claude Code and Codex.

Choosing

When to use which

creatio-mcp-go

  • everyday agent work with pages, schemas, data, applications and processes
  • many short calls where response time matters
  • a machine without .NET
  • updates without stopping the server

clio MCP

  • deploying, restoring and stopping stands, registering environments, Redis, workspaces
  • page-smoke and the mobile page guide
  • installing and updating the knowledge library, Git knowledge sources
  • a clio newer than 8.1.0.142 and its new tools
  • an unstable stand where clio’s retries during an FSM switch are needed

Together: keep clio installed for environments, knowledge and infrastructure, and route the agent’s everyday calls through creatio-mcp-go.

creatio-mcp-go v0.2.1 · clio 8.1.0.142

11 / 12

creatio-mcp-go reads the environments from clio’s appsettings.json and the knowledge library from clio’s store, so clio is needed even when every agent call goes through creatio-mcp-go. Both servers can run at the same time on one clio home: writes to the knowledge store and appsettings.json take the same file locks as clio 8.1.0.142.
